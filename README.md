A re-implementation of `printf` in C, built as a static library with flag handling.

| UNIT DATA | |
|---|---|

## ▸ Usage
```bash
make    # builds libftprintf.a
```
Link with `libftprintf.a` and include `ft_printf.h` from `include/`. Conversions: `c s p d i u x X %`, with flag parsing (`src/get_flags.c`).
